# Phased build prompts

1. **Evidence:** instrument anonymous start, completion, decision dwell, debrief usefulness, and $49 CTA; add consent copy and an experiment dashboard without collecting student identity.
2. **Practitioner integrity:** create authenticated RN review, immutable scenario versions, claim-level comments, consent signature, expiry/re-review, and a public “who reviewed this” panel.
3. **Paid wedge:** add checkout for the $49 kit, debrief scheduling, refunds, and practitioner revenue share; test payment and webhook idempotency.
4. **School pilot:** only after thresholds pass, add rosterless invite codes, aggregate completion export, accessibility review, retention policy, and counselor pilot reporting.
5. **Assisted authoring:** let AI draft from structured interviews, but require practitioner approval for every scene; log model/version and prohibit autonomous publishing.
